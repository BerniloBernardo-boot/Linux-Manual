# Glossary

> Estado: `planned` (ver `ROADMAP.md`).

## Objetivo

Fixar vocabulário PT ↔ EN com definições de uma linha + apontador para o tópico que
ensina: sem jargão ambíguo ("Linux" genérico, "terminal" vs. "shell", "free" vs.
"grátis") a documentação inteira degrada-se.

## Pré-requisitos

- Nenhum (consulta); cada verbete aponta para o eixo que o ensina.

## Documentos planeados

| Documento | Escopo |
|-----------|--------|
| `a-f.md`, `g-m.md`, `n-z.md` | Verbetes A–Z: termo PT, termo EN, 1 linha, link |

Exemplo do padrão: **kernel** — núcleo do SO (gere CPU/memória/hardware); ≠
distribuição (ver `01-fundamentos`).

## Como usar

Consulta cruzada: tópicos ligam termos aqui na primeira ocorrência; este eixo nunca
ensina sozinho, só define e encaminha.

## Notas técnicas do eixo

- Uma definição por verbete, sem ensaio; se precisa de ensaio, é tópico, não verbete.
- Termos ingleses sem tradução consagrada (`bootloader`, `pipe`, `socket`) mantêm-se
  em inglês (convenção do projeto).
